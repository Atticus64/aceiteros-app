# Aceiteros App

Aplicacion para el manejo, seguimiento de inventario, clientes, ventas
del negocio de aceite automotriz y servicios de mantenimiento que de 
solución a los negocios locales de la ciudad.

## Tecnologías

* Version de SDK: Minimo 23, target 37
* Android 5-8 para que se ejecute en el 90% de dispositivos
* Version de Kotlin: kotlin = "2.2.10"

Ver más detalles en `gradle/libs.versions.toml`
